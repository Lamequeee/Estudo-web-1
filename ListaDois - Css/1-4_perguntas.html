Atividade 1 - O que é uma regra CSS? Explique o conceito de regra CSS e forneça um exemplo prático que inclua um seletor, uma propriedade e um valor.

Uma regra CSS é uma declaração que segue uma sintexe propria de uma folha de estilo que define como um elemento se comporta e são estilizados.

Atividade 3 – Como podemos incluir CSS em documentos HTML?

CSS inline: Dentro da linha da tag.

CSS interno: No HEAD dentro do próprio HTML usando a tag style.

CSS externo: Em um arquivo .css e vinculado a uma ou várias paginas HTML.
