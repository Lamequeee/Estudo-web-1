Animação

Animate permite definirmos animações para elementos HTML, definindo o inicio.

        .box{
            width: 100px;
            height: 100px;
            background-color: red;
            animation: move 2s infine;
        --animation: name duration timing-function delay steration-count direction fill-mode;

        }

        @keyframes move{
            0% {transform: translateX(0);}
            50% { transform: translateX(100px);}
            100% { transform: translateX(200px);}
        }
