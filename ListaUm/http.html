Protocolo HTTP e como é usado na web

O papel do HTTP na comunicação entre navegador e servidor

O HTTP é o protocolo responsável pela comunicação entre o navegador e o servidor. Ele permite que páginas, imagens e outros recursos sejam solicitados e enviados pela Internet.

Cliente, servidor, requisição e resposta

O cliente é o navegador utilizado pelo usuário. O servidor é o computador que armazena os arquivos do site. Quando o usuário acessa uma página, o navegador envia uma requisição ao servidor, que responde enviando os dados solicitados.

Descrição dos métodos GET e POST;

GET:Utilizado para solicitar informações ao servidor.

POST:Utilizado para enviar informações ao servidor.

Exemplo de uma requisição HTTP;

    POST / HTTP/1.1 
    Host: foo.com
    Content-Type: application/x-www-form-urlencoded
    Content-Length: 13

Exemplo de uma resposta HTTP;

    HTTP/1.1 200 OK
    Cache-Control: no-cache, must-revalidate
    Content-Type: text/html; charset=ISO-8859-1

5 códigos de status HTTP

  • 200 OK: requisição realizada com sucesso.
  • 302 Found: redirecionamento temporário.
  • 400 Bad Request: requisição inválida.
  • 404 Not Found: recurso não encontrado.
  • 500 Internal Server Error: erro interno do servidor.
