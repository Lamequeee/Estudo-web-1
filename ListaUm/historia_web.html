Linha do tempo

  • 1960 - Surgimento das redes de computadores;
  • 1969 - Primeiro circuito da ARPANET;
  • 1969 - Começou o desenvolvimento do TCP/IP;
  • 1983 - Criação do DNS;
  • 1989 - Primeira proposta formal apresentada por Tim Berners-Lee da criação da World Wide Web;
  • 1990 - Implementação da primeira comunicação bem-sucedida entre cliente HTTP e servidor.
  • 1991 - Lançamento da primeira versão pública do HTML 1.
  • 1991 - Lançamento do primeiro site ( info.cern.ch );
  • 1995 - Lançamento do HTML 3, informção organizada para humanos e máquinas possam entender;
  • 1997 - Lançamento do HTML 4, incentivo ao uso de CSS;
  • 2014 - Lançamento do HTML5, versão atual e padrão da web. Permitiu mídias sem necessidade de plugins e semântica aprimorada
Ano Acontecimento Importancia para Web ou Internet
1960 Surgimento das redes de computadores Possibilitam a conexão global e o acesso rápido à informação e aos serviços digitais.
1969 ARPANET Base para o desenvolvimento da Internet moderna.
1989 World Wide Web Ela tornou a Internet mais fácil de usar, popularizando o acesso ao conhecimento, à comunicação e aos serviços online.
1990 HTTP Transferência de páginas, imagens e outros conteúdos pela Internet.
1991 HTML 1.0 Desenvolvimento das páginas e sites da Internet
2014 HTML 5.0 Sites mais interativos, multimídia e compatíveis com diferentes dispositivos e navegadores.
